# ViperChat 4.16.12-viper.30

- Adicionado transporte Gmail API para leitura e envio de e-mails, com os escopos
  `gmail.readonly` e `gmail.send`, preservando anexos, CC/CCO e respostas.
- Adicionada a opção **Usar Gmail API por padrão** em SuperAdmin → Google.
  O padrão de compatibilidade permanece desativado; caixas existentes mantêm
  IMAP/SMTP até serem reconectadas pelo OAuth com a opção habilitada.
- Mantida a importação de histórico, com paginação, deduplicação e checkpoints.
- Corrigida a leitura do token renovado e preservado o refresh token quando o
  provedor não retorna outro na renovação.
- Corrigida a apresentação do valor padrão dos campos booleanos no SuperAdmin.

Validação local: 136 testes de integração/regressão aprovados nas rodadas de
Gmail API, OAuth, mailer, histórico, Microsoft e SuperAdmin. O formulário foi
verificado em desktop e larguras móveis. As chamadas Google dos testes foram
simuladas; consentimento e entrega externa reais ainda exigem validação.

Configuração e migração: [Gmail API e IMAP/SMTP legado](../gmail-api-transport.md).
Habilitar a Gmail API no projeto Google e conferir os escopos e a URI de retorno
antes de reconectar uma caixa de teste. Não liberar escopos não verificados para
usuários de produção; manter o teste restrito ao ambiente/conta de homologação.

Esta release publica a imagem Docker via tag Git. Não executa deploy na VPS,
não altera o Google Console e não muda as versões nativas Android/iOS.
