# ViperChat v4.16.12-viper.32

## Sincronização de contatos com o ViperERP

- API incremental autenticada, exclusiva para administradores da conta.
- Páginas limitadas a 100 contatos, com cursor por data/ID e janela fixa.
- Atualização condicional por versão, sem substituir campos privados ou vínculos.
- Índice concorrente de contatos por conta, data e ID.
- A API regular de contatos permanece compatível.

Aplicar a migration `20261017160000_index_contacts_replication_cursor` antes de
ativar a sincronização no ViperERP. Publicar apenas o backend ViperERP não
disponibiliza estas rotas no ViperChat. A ativação continua explícita por conta;
publicar esta API não inicia uma carga de contatos por conta própria.

Esta entrega não altera frontend, Capacitor, builds móveis ou HostDbApi.
Preservar os overlays de produção existentes e conferir se algum mount de
`config/routes.rb` está sombreando as rotas da imagem nova. Não remover overlays
de outras correções sem comparar seu conteúdo com a nova imagem.

Rollback de código: retornar à imagem anterior e desativar a sincronização no
ViperERP. Manter o índice aditivo; não apagar contatos, vínculos ou checkpoints.
Publicação da imagem, migration e deploy são etapas distintas, que devem ter
seus resultados conferidos separadamente.
